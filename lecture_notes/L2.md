## Page 1 — Preliminaries: Machine & Deep Learning, Feature Extraction and Graphs

### The Core Aim of Feature Representation
The overarching goal is to **transform complex features into a space where linear models can work well** in the final representation space. This is achieved through two broad approaches:

- **① Fixed / Prior methods** — hand-crafted features (e.g., PCA, k-Means). These can be perfect (K=d) or imperfect (K<d, lower-dimensional spanning space).
- **② Learnable methods** — finding an optimal subspace for the data, typically via **matrix factorization**: `CW = X`, factoring matrix X into a product of two matrices C and W.

### Classic Feature Representation Methods in ML
- **Hand-crafted features** → Feature Selection → Classify / Regress
- **Feature Transformation / Representation** using spanning sets and encode-decode functions
- Techniques include **PCA**, **K-Means**, and **Matrix Completion**

### Supervised Regression Reminder
| Model Type | Description |
|---|---|
| Single regression | Scalar output, L2 loss: `l(w) = (1/n) Σ (x̃ᵢᵀw − yᵢ)²` |
| Multi-regression | C output scores, matrix weight W |
| Single-layer nonlinear | Adds activation function `a(·)` |
| Multi-layer (deep) nonlinear | Composed sequential transformations |

### Deep Learning: Composition & Backpropagation
A multi-layer deep network maps input features through a **final composed feature transformation**:

```
y = w_{L+1}ᵀ · a(W_Lᵀ · a(W_{L-1}ᵀ · a(... a(W₁ᵀ x) ...)))
```

- Each hidden layer applies: linear transform → activation → output to next layer
- DL = composition of functions + backpropagation for learning

## Page 2 — Feature Embedding: From ML to Graph-Based Learning

### Feature Embedding in Deep Learning & Manifold Learning

The **Da Vinci Principle** is central here: *"Simplicity is the Ultimate Sophistication"* — with more computational budget, DL models learn to compress complex data into simpler manifolds.

**Key insight:** The power of DL lies in learning to embed complex features **sequentially** into manifolds (subspaces) of decreasing complexity, until finding an ultimate low-dimensional representation space where linear models work well.

### What is Manifold Learning?
An **embedding function** `f: ℝᵈ → ℝᵈ'` maps from extrinsic dimension `d` to intrinsic dimension `d'`, where `d' < d`. The underlying distributions of the noise `ε` and the function `f(xᵢ)` are **unknown**.

**Reductionist hypothesis:** Neighborhood preservation across original and embedding spaces.  
**Limitation:** The neighborhood in the original domain may be highly noisy (outliers in local neighborhoods).

### The Evolving Landscape: From Individualistic to Collectivist

| Paradigm | Description |
|---|---|
| **Individualistic (ML)** | Data samples live independently on a high-dimensional manifold. A shared mapping `w` is learned across all training samples, but samples do **not** directly interact. |
| **Manifold Learning** | We learn to calculate similarity between points, but still not how to *connect* them. One step away from graphs. |
| **Collectivist (Graph-Based)** | Data samples **co-interact and co-learn** via a graph structure `A`. Each sample interacts with all others. |

### Graph Representation
A graph `G = (V, E, A)` encodes relationships between samples via an **adjacency matrix A**:
- Node features: `X ∈ ℝⁿˣ⁽ᵈ⁺¹⁾`
- Edge features can also be added

### Classical Feature Extraction on Graphs
Three types of graph features:
1. **Node-based features** — local node properties (e.g., degree, centrality, connectivity)
2. **Edge-based features** — single edge `eᵢⱼ` represented by a function of node features (0.5 × feature distance)
3. **Graph-based features** — global graph stats (e.g., upper triangular part of adjacency, `n(n+1)/2` elements)

**Limitations of classical approaches:**
- Cannot utilize node, edge, and graph features jointly
- Cannot obtain embeddings for nodes **not** in the training set — adding a new node requires recomputing all embeddings

## Page 3 — Graph Convolutional Networks (GCNs): The Shallow Single Layer

### Classical Node Encoding / Embedding (No Features)
Given a graph `G = (V, E)`, learn a node embedding `z_u ∈ ℝᵈ'` that encodes the network structure.

**Constrained Embedding:** Preserve the local structure/neighborhood of the graph:
- Objective: maximize `f(u)ᵀ f(v) = z_uᵀ z_v` for pairs `(u,v)` that are close/similar
- Similarity `(u,v) ≈ z_uᵀ z_v ≈ f(h)ᵀ f(v)`

The embedding matrix `Z ∈ ℝⁿˣᵈ'` stores all node embeddings (one per row).

**How to define node similarity?** Nodes are similar if they:
- Are connected
- Share neighbors
- Have similar topological roles

**True or False:**
- ❌ Shallow node embedding is task-dependent (not unsupervised)
- ✅ Node embedding is supervised or self-supervised
- ❌ We **do** utilize node labels and features for embedding

### Our Goal: The Paradigm Shift
> Shifting from an **"individualistic"** to a **"collectivist"** learning paradigm through the graph matrix `Â`

The GCN goal: embed via F, all learnable transformations per layer, maps one layer's data to the next:

```
H₁ = F(X, A, φ₀)
H₂ = F(H₁, A, φ₁)
H₃ = F(H₂, A, φ₂)
...
Hₖ = F(Hₖ₋₁, A, φₖ₋₁)
```

### A Vanilla GCN Layer

The modified adjacency matrix with self-loops:  
`Â = A + I`  
*(The output of a node in a hidden layer depends on itself and its neighbors.)*

**Propagation rule:**
```
H_{k+1} = a(Â Hₖ Ωₖ)
```
Where:
- `Hₖ` = node embeddings at layer k (H₀ = X)
- `Ωₖ` = learnable transformation (weight matrix) at layer k
- `a(·)` = nonlinear activation function

### Linearizing the Network (Removing Nonlinearity)

Without activation:
```
H₁ = Â H₀ Ω₀
H₂ = Â H₁ Ω₁ = Â² X Ω₀Ω₁
H₃ = Â³ X Ω₀Ω₁Ω₂
H_{k+1} = Âᵏ⁺¹ X · Ω₀Ω₁...Ωₖ   (composed transformation across layers)
```

**Important property of Â^(k+1):** For each node `i`, this matrix stores the **total number of walks of length (k+1)** from node `i` to node `j`. If `0`, node `j` is unreachable in k+1 hops.

This defines the **receptive field** — the k-hop neighborhood a node can "see."

### Layer-wise Normalization and Propagation Rule

**Normalized propagation rule:**
```
H_{k+1} = a(D̂⁻¹ Â Hₖ Ωₖ)
```
- Controls the **latent embedding variance** between layers → suppresses gradient explosion/vanishing
- Maintains the **scale** of output feature vectors

**Generalized propagation rule:**
```
H_{k+1} = f(Hₖ, Â)
```
(`A` is fixed, not learned — the graph structure is given)

## Page 4 — GCNs: Going Deeper, Node Embedding Update Rules

### Node Embedding Update Rule (Single Node)

**Message aggregation across neighbors:**
```
agg[n, k] = Σ_{m ∈ N(n)} h_m^(n)
```

**Node update rule:**
```
h_{k+1}^(n) = a[ β_k + Ω_k · h_k^(n) + Ω_k · agg[n, k] ]
              = a[ β_k + Ω_k · h_k^(n) · (A + I) ]
```
- `β_k` = bias at layer k
- `Ω_k` = shared weight matrix
- Self-update + neighborhood aggregation

**Update Rule for All Nodes (Matrix Form):**
```
H_{k+1} = a[ β_k 1ᵀ + Ω_k Hₖ (A + I) ]
         = a[ β_k 1ᵀ + Ω_k Hₖ Â ]
```

### How to Combine the Current Node and Aggregated Neighbors?

#### Option 1: Simply Sum Them Up (Vanilla GCN)
```
H_{k+1} = a[ β_k 1ᵀ + Ω_k Hₖ (A + I) ]
```
Using `Â = A + I` naturally folds self-aggregation into the neighborhood aggregation.

#### Option 2: Add a Diagonal Enhancement
```
H_{k+1} = a[ β_k 1ᵀ + Ω_k Hₖ (A + (1 + ε_k)I) ]
```
- `ε_k` = learnable scalar per layer to control how much influence the node itself gets vs. its neighbors.

#### Option 3: Treat Current Node Differently (Separate Transform Ψ_k)
```
H_{k+1} = a[ β_k 1ᵀ + Ψ_k Hₖ + Ω_k Hₖ A ]
         = a[ β_k 1ᵀ + [Ω_k  Ψ_k] [Hₖ A; Hₖ] ]
         = a[ β_k 1ᵀ + Ω̃_k [Hₖ A; Hₖ] ]
```
- Self-transformation `Ψ_k` is **separate** from neighbor transformation `Ω_k`
- More expressive — allows the model to distinguish self-features from aggregated neighbor features

### Example: Graph Classification

Deep sequential node representation:
```
H₁ = a[β₀ 1ᵀ + Ω₀ X(A + I)]
H₂ = a[β₁ 1ᵀ + Ω₁ H₁(A + I)]
...
Hₖ = a[βₖ₋₁ 1ᵀ + Ωₖ₋₁ Xₖ₋₁(A + I)]
```

**Network Output Function (Graph-level prediction):**
```
f(X, A, Φ) = sig[ β_K + ω_K (Hₖ 1/N) ]
y = sig[ β_K + ω_K (Hₖ 1) / N ]
```
- Average the node embeddings across all N nodes → graph-level representation
- Pass through sigmoid for classification
- Output: class probabilities (e.g., 0.9 for Class 1, 0.1 for Class 2)

## Key Takeaways

1. **Feature embedding** is about transforming high-dimensional data into compact, low-dimensional spaces where linear models work well — achieving "simplicity" from complexity.

2. The shift from **individualistic** (standard ML/manifold learning) to **collectivist** (graph-based) learning is the central conceptual leap: samples are no longer isolated but co-interact via a graph adjacency matrix.

3. **GCNs** extend deep neural networks to graphs by propagating node features through the adjacency matrix at each layer — implementing a form of **message passing**.

4. The **vanilla GCN propagation rule** `H_{k+1} = a(Â Hₖ Ωₖ)` with `Â = A + I` naturally aggregates each node's own features with its neighbors'.

5. **Layer-wise normalization** via the degree matrix `D̂` prevents gradient explosion/vanishing and keeps embedding scales stable.

6. More expressive GCN variants use **separate weight matrices** for self-aggregation vs. neighborhood aggregation.

7. For **graph-level** tasks (e.g., graph classification), node embeddings are pooled (e.g., averaged) into a single graph-level vector before final prediction.
