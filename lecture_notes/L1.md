## Page 1 — What Is a Graph? Graph Types & Matrix Representation

### What Is a Graph?

Graphs are powerful tools for **modeling interactions and relationships** between different elements. By modeling such dependencies in a reliable way, one can derive rules, predictions, or new knowledge about the system at hand.

**Real-world examples of graphs:**
- **Social networks** — nodes are people, edges represent friendships
- **Scientific literature** — nodes are papers, edges represent citations
- **Wikipedia** — nodes are articles, edges represent hyperlinks between articles
- **Computer programs** — nodes are syntax tokens (variables in the program flow), edges represent computations involving those variables
- **Geometric point clouds** — each point is a node, edges connect points to other nearby points
- **Protein interactions** — nodes are proteins, edge between two proteins if they interact

A graph is formally denoted as `G = (V, E)` or with features as `G = (V, E, A_i, X, E)`, and is typically represented through three matrices:
- **Adjacency matrix `A`** — encodes connectivity (binary/weighted)
- **Node feature matrix `X`** — encodes node attributes/embeddings
- **Edge feature matrix `E`** — encodes edge attributes/embeddings

---

### Graph Types

#### 1. Directed vs. Undirected / Binary vs. Weighted

**Directed graph:** `A_{i,j} ≠ A_{j,i}` — edges have direction (asymmetric adjacency matrix)
- Example: `b_{i,j} = 0`, `b_{k,j} = 1`

**Undirected graph:** `A_{i,j} = A_{j,i}` — edges have no direction (symmetric adjacency matrix)
- Example: `e_{i,j} = e_{j,i}`

**Binary graph:** `A_{i,j} ∈ {0, 1}` — edges either exist or don't

**Weighted graph:** `A_{i,j} ∈ ℝ` — edges carry a real-valued weight
- Example: `w_{ij} = 0.9`, `w_{ij} = 0.5`

#### 2. Simple Graph
A graph is **simple** if it has:
- **No loops** (no self-connections — an edge that connects a node to itself)
- **No multiple edges** (no two routes connecting the same two nodes)

#### 3. Complete Graph
A graph where **each of its nodes is connected to all other nodes** — every two nodes are adjacent.

Properties:
- N nodes in G
- ∀ node `i` connects to `(N-1)` nodes
- `N(N-1)/2` edges (excluding self-connections)

#### 4. Subgraphs
Used to examine the structure of graphs that lie within a given graph.

- A graph `H` is called a **subgraph** of `G` if every vertex and edge of `H` belong to `G`:
  `V(H) ⊆ V(G)` and `E(H) ⊆ E(G)`
- A graph `G` is a **subgraph of itself**
- All other subgraphs are **proper subgraphs**
- If `H` is a subgraph of `G` having the **same vertices** as `G`, then `H` is a **spanning subgraph** of `G`

#### 5. Induced Subgraphs
Given a non-empty subset `S ⊆ ∅` of nodes of `G`, the **subgraph `G[S]`** of `G` induced by `S` has vertex set `S` where two vertices `u` and `v` are adjacent if and only if they are adjacent in `G`.

*(Are subgraphs `H₁` and `H₂` induced? — this is an important question when examining graph structure.)*

#### 6. Annotated / Decorated Graphs
A graph `G` is **annotated or decorated** if its nodes can hold **attributes / features**:
```
G = ((V, X), E)
```
Where `X ∈ ℝ^{n × d}` is the node feature matrix — also called the **feature/embedding matrix**.

#### 7. Heterogeneous Graphs
A **heterogeneous graph** `G = (V, E)` contains **multiple types of nodes and edges** (in contrast to a homogeneous graph where all nodes and edges are of the same type).

- Nodes with different **types** `τ ∈ V` (e.g., year, paper, topic, city)
- Edges with different **relation types** `r ∈ E` (e.g., cite, write, belong-to)
- The **triple** `(τ_i, r_{ij}, τ_j)` encodes the relationship between node types

Example: a knowledge graph with nodes for `year`, `paper`, `topic`, connected by `cite`, `belongs-to` relations.

#### 8. Hypergraphs
A **hypergraph** `H` is a **generalization of a graph** in which an edge can join **any number of vertices** (not just two):
- Models **higher-order relationships** among nodes — unlike typical graphs (pairwise)
- It is a set of **non-empty subsets** (or **hyperedges**)
- Represented via an **incidence matrix** (rather than an adjacency matrix)
- A hyperedge `e_k` can connect `V₁`, `V₂`, `V₃`, `V₄` simultaneously

### Graph Representation into Matrices

A graph `G = (N, V, E)` with node and edge embeddings can be represented by three matrices:

**(a) Adjacency matrix `A`:** N × N binary/weighted matrix of connections.
Each node has an associated embedding of length five (shown as row vectors). Each edge has an associated embedding of length four (blue vectors). The graph can be represented by three matrices.

**(b) Node feature matrix `X`:** N × d matrix. When `A` is created, nodes are all-zeros (no features yet) and are later enriched. The scale matrix `W` encodes node embeddings.

**(c) Edge feature matrix `E`:** The edge item matrix `B` contains the edge embeddings.

## Page 2 — Graph (Matrix) Properties

All properties are derived from the core **adjacency matrix `A` (N × N)**, which sits at the center of graph analysis.

---

### 1. Connectivity: Symmetric vs. Asymmetric Matrix

**Directed (Asymmetric):** `A_{i,j} ≠ A_{j,i}` — directed edges
**Undirected (Symmetric):** `A_{i,j} = A_{j,i}` — undirected edges
**Binary:** `A_{i,j} ∈ {0, 1}`
**Weighted:** `A_{i,j} ∈ ℝ`

---

### 2. Scale/Size (Density, Sparsity) & Permutation Invariance

**Node size:** `|V|` = number of nodes (size of graph)
**Edge count:** `|E|` = number of non-zero elements in `A`
**Density:** ratio of non-zero elements in A to total possible edges
**Sparsity:** a matrix is sparse if most elements are zero

**Graph size:** `A ∈ ℝ^{N×N}`

**Permutation invariance:** If we permute the node indices using a permutation matrix `P`:
```
X' = X · P     (permuted node feature matrix)
A' = PᵀAP     (permuted adjacency matrix)
```
The graph remains the same — only the **indexing** changes. This is critical for GNN design (Lecture 5).

---

### 3. The Power of Integrating Information

The adjacency matrix encodes **neighborhood** information. Multiplying `A` by a feature vector `v` aggregates/integrates information along node neighbors:
```
A × v → aggregated neighborhood embedding
```

This is the basis of GCN message passing:
- `A ∈ ℝ^{n×(d+1)}` × `w ∈ ℝ^{d+1}` = `ŷ ∈ ℝⁿ` (predicted scores)
- `f(x) = (1/n) Σ(x_i² − y_i)²` (loss over aggregated scores)

The power of graph-based learning lies in the ability to **aggregate and integrate information along both nodes and their neighborhood**.

---

### 4. Topology

**Topology** captures the structural role of each node and each edge in the graph, quantified at multiple scales:

**Node-level (microscale topology):**
- **Degree centrality:** `d_i = Σ_{j∈N(i)} w_{ij}` — the weighted sum of all edges connected to node `i`; quantifies the **topological role of a node**

**Edge-level (mesoscale topology):**
- Quantifies the topological role of an **edge** `e_{ij}`
- **Topological measures:** betweenness centrality, etc.

**Organization patterns (macroscale topology):**
- From microscale → mesoscale (organization, communities) → macroscale (components, hubs, periphery)

**Key questions about topology:**
- How do the topological properties of graphs constrain the way in which information flows through the graph?
- Which specific graph properties can be used to gain insight into information processing by graph units (nodes/edges)?

---

### 5. Walks (Powers of Matrices)

**A walk of length k** from node `i` to node `j` counts the number of paths of exactly `k` steps.

**Key property:** `(A^k)_{ij}` = number of walks of **length `k`** from node `i` to node `j`.

**Example:** If `A²_{ij} = 3`, there are 3 distinct walks of length 2 from `i` to `j`.

**Properties of the adjacency matrix `A`:**
- `A` contains the number of walks of length 1 between nodes
- `A²` contains the number of walks of length 2
- `Aᵏ` contains the number of walks of length k

This property is **directly exploited** by GCNs — stacking `k` layers captures k-hop neighborhoods. The `(k+1)`-th power of `Â` counts walks of length `k+1`, which defines the **receptive field** of a node.

---

### 6. Spectra of the Matrix (Eigen Decomposition)

Eigen decomposition applies to different matrix types:

**General matrix:**
```
M = E · Λ · E⁻¹     (M not necessarily symmetric)
```

**Covariance matrix** (symmetric positive semi-definite):
```
S = U · Λ · Uᵀ
```
The eigen decomposition is **spectral decomposition** — eigenvectors are orthonormal.

**Adjacency matrix** (symmetric for undirected graphs):
```
A = U · Λ · Uᵀ     (eigenvalues Λ, eigenvectors U)
```
- Eigenvectors represent **spectral connectivity** of the graph
- The eigenvalues characterize global graph structure
- Spectral methods in GNNs exploit this decomposition

**General eigen decomposition:**
```
M = eigenvalues × eigenvectors
```
Where the eigenvectors form the **embedding space** of the graph.

---

### 7. Organization Pattern

The **organization pattern** captures structure at multiple scales:

**Microscale topology → node centrality measures:**
- Local structural properties of individual nodes
- Degree, clustering coefficient, betweenness, etc.

**Mesoscale topology → organization:**
- Community structure, modules, motifs
- How nodes cluster into densely connected groups

**Macroscale topology → components, hubs & periphery:**
- Global connectivity: connected components, hubs (highly connected nodes), periphery nodes
- **Hub nodes** — highly connected, more efficient information flow
- **Peripheral nodes** — low connectivity, less efficient

Key observation: Graphs with more **heterogeneous** topology (mix of hubs and periphery) tend to have higher efficiency in information flow than regular or random graphs.

---

### 8. Efficiency and Resilience

**Two key graph-level questions:**
1. How do the **topological properties** of graphs constrain the way information flows through the graph?
2. Which **specific graph properties** can be used to gain insight into information processing by graph units (nodes/edges)?

**Efficiency:** Relates to information flow globally (across the whole graph) and locally (within neighborhoods).
- Global efficiency ↑ with hub-and-spoke topology
- Local efficiency relates to clustering

**Resilience:** The ability of a graph to maintain connectivity and function despite the removal of nodes or edges. Resilience depends on whether hubs or peripheral nodes are targeted.

## Page 3 — Learning Tasks on Graphs

Three fundamental learning tasks can be performed on graphs using GNNs:

---

### 1. Graph Classification

**Goal:** Classify a graph as a whole (e.g., is this molecule toxic or not? Is this protein functional?)

**Pipeline:**
```
Input graph → Graph Neural Network → Combine node embeddings → Classify → Class label
```

**Mathematical formulation (A is fixed):**
```
y = sig[ β_K + ω_K H_K 1/N ]
```
Where:
- `H_K` = K-th layer node embeddings (N × D matrix)
- `ω_K` = learned weights (1 × D)
- `1/N` = averaging "1" vector of size N (mean pooling across all N nodes)
- `β_K` = learned bias
- `sig(·)` = sigmoid activation → predicted class probability

**Dimension breakdown:**
```
(1 × D) × (D × N) × (N × 1) = 1 × 1   → scalar class score
```

**Logistic activation (Sigmoid):**
```
σ(x) = 1 / (1 + e^{-x})     (smooth approximation of a step function)
d/dx σ(x) = σ(x) · (1 − σ(x))
```
Used for **classification** — maps any real value to `(0, 1)`.

---

### 2. Node Classification

**Goal:** Classify individual nodes within a graph (e.g., identify the category of a social network user, label a node as 'cat' or 'dog').

**Pipeline:**
```
Input graph → Graph Neural Network → Node embeddings → Classify each node
```

**Mathematical formulation (A is fixed):**
```
y_K^(n) = sig[ β_K + ω_K h_K^(n) ]
```
Where:
- `h_K^(n)` = K-th layer embedding of node `n` (the **node embedding**)
- `ω_K` = learned weights
- `β_K` = learned bias
- `σ(x)` → `y^(c)` = predicted class label for node `n`

**Mapping function:** `ω_K × [node embedding] = c_K^n + β_K` → `σ(x)` → `y^(c)` (maps onto a target value — classification/label).

---

### 3. Edge Prediction (Link Prediction)

**Goal:** Predict whether an edge (link) exists between two nodes — or predict a missing edge in an incomplete graph (e.g., predict friendships in a social network, predict drug-protein interactions).

**Pipeline:**
```
Input graph → Graph Neural Network → Node embeddings → Predict edge presence from adjacent embeddings
```

**Mathematical formulation:**
```
y^(mn) = sig[ h^(m)ᵀ h^(n) ]
```
Where:
- `h^(m)` = embedding of node `m`
- `h^(n)` = embedding of node `n`
- `h^(m)ᵀ h^(n)` = **dot product** of the two node embeddings (measures similarity/compatibility)
- `sig(·)` → probability of link existence
- `y^(mn) ∈ {0, 1}` (binary: edge exists or not)

---

### Generalized Prediction Framework

All three tasks are unified under a **generalized prediction framework** operating at different levels of the graph:

```
Generalized {  node-level    }
             { edge-level    } prediction
             { graph-level   }
```

For any given node in the graph, one can:
- **Label / classify** it
- **Score / regress** it
- **Generate another graph from it**

And the same applies at the edge and graph level.

**Key insight:** The same GNN backbone (message passing + embeddings) can be repurposed for all three task types — only the **prediction head** changes.

## Key Takeaways

1. **Graphs** are the natural representation for relational data — social networks, molecules, brain connectivity, knowledge graphs — encoding entities as nodes and relationships as edges.

2. **Eight graph types** cover the spectrum from simple/complete to directed/undirected, weighted/binary, heterogeneous, hypergraph, and annotated graphs — each with different structural properties and use cases.

3. A graph is fully encoded by up to **three matrices**: adjacency `A` (topology), node features `X` (node attributes), and edge features `E` (edge attributes) — all required for GCN learning.

4. **Eight key graph/matrix properties** characterize its behavior: connectivity (symmetric/asymmetric), scale (density/sparsity) and permutation invariance, information integration power, topology, walks (matrix powers), spectral decomposition (eigenvalues/vectors), organization patterns (micro/meso/macroscale), and efficiency/resilience.

5. **Matrix powers `Aᵏ`** count walks of length `k` between all node pairs — directly analogous to the k-hop neighborhood captured by stacking k GCN layers.

6. **Spectral decomposition** of the adjacency matrix (`A = UΛUᵀ`) exposes the graph's frequency structure and underpins spectral GNN methods.

7. The **three core graph learning tasks** — graph classification, node classification, and edge/link prediction — all share the same GNN backbone but differ in their prediction head: mean-pooled embeddings for graph-level, per-node embeddings for node-level, and dot-product of node pairs for edge-level.
